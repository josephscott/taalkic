# taalkic

A PHP web framework built on Workerman ( no support for PHP-FPM ).

## Notes

The @notes/ directory contains Markdown files that have more information
about specific areas of the project.  Before you ask any questions, search
those Markdown files to see if they already have the details you need.

## After Every Change

Any time you make a change to the code of taalkic run `make all` to confirm
that all of the checks and tests still pass.
